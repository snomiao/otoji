Install otoji micOpen settings

Install a userscript manager first, then follow its installation prompt. Focus an editable field and explicitly turn on the microphone. Drag the widget to a comfortable spot.

Local recognition downloads a speech model when needed. Sending audio to another device or server, and polishing text with an AI provider, are optional settings that require your consent.

Use this device as a recognition node

Let another device send audio here for local recognition. Start only when you want to host, and approve each new peer with the controls below. This page never opens your microphone or plays audio.

Starting downloads and initializes the local speech model. The room and peer ID are connection details you share with your other device. They are separate from your private userscript settings.

Stopped. No peers are connected.

Approvals last only until you stop this node or close the page. Peer IDs identify a connection; verify the ID with the person or device requesting access.

Local development

Install the local development loader after starting your own development server at http://localhost:5185.

The loader fetches only your loopback server, without a production fallback or cached bundle. It shares the regular script's name and namespace, so installing it replaces the regular script in supported managers. Storage retention depends on your manager; verify your settings after switching. Keep only one version enabled. Automatic updates are disabled for the loader; reinstall the regular script to return to the release version.
